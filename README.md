# EMS

Employee Management System built with the MERN stack (MongoDB, Express, React, Node.js).

## Project structure

- `Backend` — Express API, MongoDB, authentication, staff and tasks
- `Frontend` — React (Vite) admin dashboard

## Getting started

### Backend

```bash
cd Backend
npm install
npm run dev
```

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

Create a `Backend/.env` file for local settings (port, MongoDB URI, JWT secret, client URL). Do not commit this file.
